# Portfolio-ah-site
## 1. Project Description - Personal portfolio ah site
### Tech Stack
Rust, HMTL , CSS , JavaScript 

## 2. Setup & Execution Steps

### Prerequisites
- Bonezegei (BSL) command-line tool installed and added to the system PATH.
(you can search it in the microsoft store)
double check if you have it installed with the 
bzg -v 
command in powershell (double check)
-clone this https://github.com/msuiit-ph/BSL_HTTP_and_WebSocket as a template edit as you like 
-THEN
# install all dependencies
bzg install

# run the app
bzg run 

it should show( [bzg run] Starting 'start': bonezegei app.bzg ) in the terminal
